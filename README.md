# Dependency License Drift

Dependency License Drift is a standalone GenLayer Intelligent Contract primitive for package consumers who fund a covenant around a dependency version line. Validators compare authoritative package-registry metadata and SPDX license terms, then decide whether a later version materially drifts outside the locked use profile before any credit or review-required state changes.

Target network: `testnet-bradbury`.

Status: design scaffold. Contract source, tests, deployment, public repository push, and Portal submission are pending.
