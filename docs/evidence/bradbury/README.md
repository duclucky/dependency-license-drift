# Bradbury Evidence

This directory is reserved for sanitized Bradbury deployment and lifecycle evidence.

Rules:

- Keep only allowlisted public fields such as network, source commit/hash, contract address, transaction hash, execution result, and explorer URL.
- Do not store raw Studio receipts, traces, validator config, stdout, stderr, private keys, or `.env` values.
- Bradbury only: do not mix Studionet, Asimov, or localnet addresses and receipts here.
